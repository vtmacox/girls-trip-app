# Girls Trip
This app is used to plan a trip between friends.  Currnetly it takes two airports and determines the overlapping destinations between those airports, determines the flight times from each of the respective airports to the overlapping destination and calculates the absolute difference between the two flight times to help the user find the destination that is most equidistant
